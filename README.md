# Flare — web test build

Play: https://dorisyluo.github.io/flare-web/

**Keyboard:** hold W / S to move between lanes (ball snaps back to the middle on release) · SPACE to hit (hold for long notes) · D to ignite FLARE · ESC to pause

**iPad / touch (landscape):** left side — touch and swipe up / down (hold) to change lanes · right side — tap to hit, hold for long notes · swipe right on the right side to ignite FLARE · ⛶ button (bottom-left) for fullscreen

Test build for playtesting only.
